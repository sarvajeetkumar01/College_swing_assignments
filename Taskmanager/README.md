# Task Manager - Java Swing

Author: Sarvajeet Kumar  
Roll No: Y25271035  

## Description
Task Manager is a desktop application built using Java Swing and SQLite database.  
This application helps users manage their daily tasks efficiently.

## Features
- Add Task
- Update Task
- Delete Task
- View All Tasks
- SQLite Database Integration
- Simple and User-Friendly Interface

## Technologies Used
- Java
- Swing (GUI)
- SQLite
- JDBC

## Project Structure

TaskManager/
├── src/
├── dist/
├── task.db
├── manifest.mf
└── README.md

## How to Run

### Option 1: Run JAR File
1. Go to dist folder
2. Run TaskManager.jar

### Option 2: Run from Source
1. Open project in NetBeans / IDE
2. Run TaskManager.java
